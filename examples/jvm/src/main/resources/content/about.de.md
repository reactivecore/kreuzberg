# Über Kreuzberg

Kreuzberg ist ein minimalistisches Web-Framework für Scala 3 und Scala.js.
Diese Seite ist eine Markdown-Datei, die auf dem Server in der Sprache der Seite gerendert wird.

| Engine       | Rendering   |
|--------------|-------------|
| engine-naive | im Browser  |
| engine-server| auf dem Server |

Inhaltsdateien
: Eine Datei pro Sprache, z. B. `about.de.md`{.file}, mit `about.default.md`{.file} als Rückfall.

Der Quellcode liegt auf [GitHub](https://github.com/reactivecore/kreuzberg).
