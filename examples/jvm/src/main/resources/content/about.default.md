# About Kreuzberg

Kreuzberg is a minimalistic web framework for Scala 3 and Scala.js.
This page is a Markdown file, rendered on the server in the language of the page.

| Engine       | Rendering   |
|--------------|-------------|
| engine-naive | in browser  |
| engine-server| on server   |

Content files
: One file per locale, e.g. `about.de.md`{.file}, with `about.default.md`{.file} as fallback.

The source code is on [GitHub](https://github.com/reactivecore/kreuzberg).
